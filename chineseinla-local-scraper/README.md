# 招聘采集与 Notion 参数

参数页面：[参数](https://www.notion.so/3e4c18c6fba481848f78ee4b910d25b0)，位于“招聘信息监控”下面。
修改页面最上方两个普通文本段落，保留字段名：

```text
循环间隔（分钟）：3-5
日期：当天
```

- 间隔可为正数分钟（例如 55.5）或范围（例如 3-5，每轮随机选择 3 到 5 分钟）。第一轮立即执行，此后每轮完成后等待指定间隔。
- 日期为 `当天`、留空或 `YYYY-MM-DD`；当天按洛杉矶时区计算。
- 每轮开始重新读取参数，修改将在下一轮生效，不打断当前等待。
- 字段无效、缺失或重复时，该项使用默认值：60 分钟、当天。读取页面异常时两项均用默认值，不输出原因。
- 某轮运行异常不退出，等待后继续。Ctrl+C 停止。

## 运行

```bash
pip install requests lxml tzdata
python ChineseInLA_local_scraper_cli.py
```

在脚本目录放置 `notion_token.txt`，或设置 `NOTION_TOKEN` 环境变量，不能提交凭据到 Git。
Token 需要读取参数页面、读取招聘信息监控以及创建日期子页面和添加内容的权限。

只执行一轮：`python ChineseInLA_local_scraper_cli.py --once`。
只保存 CSV（仍读取参数）：`python ChineseInLA_local_scraper_cli.py --local-only --once`。

兼容旧参数：`--date-page "Notion页面链接或ID"` 从该页面标题读取唯一日期，优先覆盖参数页面的日期。
读取失败则静默回退当天。标题支持 `2026-09-22`、`2026/9/22`、`2026年9月22日`。

## 筛选与存储

按桌面详情页“发布于”或“更新于”判断，任一日期匹配就收录；保留招聘类型和置顶筛选。
先检查日期，符合条件才读取手机详情正文；处理完当前页后，若本页普通帖子日期均早于目标日期，则结束本轮；置顶帖不参与边界判断。日期缺失或解析失败时不贸然认定越界。
历史刷新只能依据网站当前显示的信息，不能还原后续刷新覆盖的历史日期。

普通帖写入“招聘信息监控”下的 `YYYY-MM-DD` 子页面；置顶帖写入同级“置顶”子页面。两类帖子都要求发布或刷新日期符合目标日期。子页面存在则复用并追加。
保留已有内容；重复运行可能重复追加。没有匹配记录时不创建空日期页面。
Notion 写入成功后保存本地 CSV。默认当天模式跨午夜停止本轮写入，下轮重新计算当天；指定日期模式保持指定日期。
若 Token 或写入权限失效，无法完成写入，但程序会等待后继续下一轮。

验证（不访问网络、不写 Notion）：`python -m unittest -v test_today_sync`。
